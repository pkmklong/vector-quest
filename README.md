# Vector Quest

A 2D game that teaches neural network concepts through gameplay. Navigate a "vector" through neural network architectures.

![Godot 4](https://img.shields.io/badge/Godot-4.5-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## [Play Now](https://pkmklong.github.io/vector-quest/)

## How to Play

- **Arrow Keys / WASD** - Move
- Pass through **INPUT** to start
- Manage activation/state through network elements
- Reach **OUTPUT** above threshold to win
- **BCE score** measures accuracy (lower = better)

## Levels

1. **Dense NN** - Avoid dropout, collect weights, pass through ReLU
2. **CNN** - Dodge sweeping kernels, collect MAX pools
3. **LSTM** - Avoid forget gates, collect input/hidden state
4. **Transformer** - Avoid masks, collect Q/K/V attention tokens

## Run Locally

Requires [Godot 4.5+](https://godotengine.org/download). Clone repo, open `project.godot`, press F5.
